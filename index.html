How it works

One frame, four steps

  1. Read the frame. Noisy colour plus clean guide buffers from Unreal: base colour, normals, depth and camera motion.
  2. Work at 1/3 resolution. Averaging 3×3 pixels gives the network nine samples per input pixel, which is both faster and cleaner.
  3. Denoise with memory. A recurrent U-Net carries its state from frame to frame, warped along the motion, so the result stays steady.
  4. Restore detail and colour. Lighting is upsampled and multiplied by the full-resolution textures, then a tile-wise colour correction keeps the original hues.
Known limits

Where it still struggles

  • Very dark interiors. When almost no pixel catches light, the output can show soft dark smudges.
  • Fine lighting detail. Sharp shadow edges and mirror reflections come out softer than in a fully converged render.
  • Sky edges. A faint bright halo can appear where buildings meet a bright sky.
  • Speed. About 30 fps today on a mid-range GPU; an FP16 version is the next step toward 60.
